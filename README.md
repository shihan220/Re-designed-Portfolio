# Re-designed Portfolio

This repository starts from the current portfolio codebase and splits the work into simple branches so it stays easy to manage.

## Branches

- `main`: overview, shared baseline, and branch guide
- `front-end`: UI, content, layout, styles, and general website polish
- `backend`: future API, real-time features, auth, storage, and server-side work
- `animation`: Three.js scene work, motion, camera behavior, transitions, and visual effects

## How to use this repo

1. Use `front-end` for page/content/style changes.
2. Use `animation` for scene and motion changes.
3. Use `backend` only when you add server-side features.
4. Merge stable work back into `main`.

## Project notes

- The current codebase is mostly front-end and animation focused.
- There is no standalone backend implementation yet, so the `backend` branch is prepared as a clean place to grow that work.
- The original project setup instructions are in `PROJECT_README.md`.
