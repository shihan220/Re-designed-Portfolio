# GitHub Activity Workflow

To keep the repository active without making it confusing:

1. Make small, real commits on the branch that matches the work.
2. Use clear commit messages tied to one change at a time.
3. Push each branch regularly instead of batching everything into one large update.
4. Merge finished work into `main` only after the branch is stable.

Suggested rhythm:

- `front-end`: content, UI, and style improvements
- `animation`: motion, effects, and scene tuning
- `backend`: server or integration work when that starts
