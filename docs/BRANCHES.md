# Branch Guide

## `front-end`

Use this branch for:

- page structure
- menu and content updates
- style changes
- asset swaps
- general polish

Main files to touch:

- `sources/index.html`
- `sources/style/`
- `sources/data/`

## `animation`

Use this branch for:

- Three.js scene updates
- camera motion
- GSAP transitions
- effects and interactive motion

Main files to touch:

- `sources/Game/`
- `sources/threejs-override.js`

## `backend`

Use this branch for:

- API ideas
- websocket/server work
- persistence
- auth

Current related client-side file:

- `sources/Game/Server.js`
